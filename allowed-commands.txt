# Claude Code - pre-approved read-only / non-destructive shell commands
# One entry per line. Blank lines and lines starting with # are ignored by the sync script.
# Run sync-claude-permissions.sh to apply changes to ~/.claude/settings.json.
#
# Format: either a bare tool name (Read, Glob, Grep) or Bash(<prefix>*)
# Bash rules use prefix matching: Bash(git log*) allows "git log", "git log --oneline", etc.
# Caveat: prefix matching cannot restrict flags, only command prefixes.
#
# Excluded intentionally (destructive or can exec arbitrary commands):
#   cp mv rm rmdir mkdir ln unlink chmod chown chgrp touch truncate shred dd tee
#   install mkfifo mknod sync csplit split patch ed ex kill renice at cron
#   xargs nohup nice stdbuf timeout chroot m4 ipcrm tar unzip zip
